# Arco brand assets

The Arco logo, as used by Arco Cloud (copied from `arco-cloud/public/favicon.svg`).

| File | Use |
|---|---|
| `arco-logo.svg` | The logo, vector (32×32 viewBox). Use it for the app icon source and in the UI. |
| `arco-logo-1024.png` | 1024×1024 PNG render, for places that need a bitmap (app icon generation, store listings). |

## Colors and type (from Arco Cloud)

| Token | Value |
|---|---|
| Logo tile | `#C93F1C` |
| Logo glyph | `#FFFFFF` |
| Primary, light theme | `oklch(0.564 0.18 34.7)` (white text on it) |
| Primary, dark theme | `oklch(0.727 0.173 39)` (dark text on it) |
| Font | Instrument Sans, then `ui-sans-serif, system-ui, sans-serif` |

Keep the logo's proportions and colors; do not recolor the tile.
